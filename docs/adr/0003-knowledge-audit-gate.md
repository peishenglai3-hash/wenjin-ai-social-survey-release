# ADR-0003：知识材料先审计、后导入运行时

- 状态：Accepted
- 日期：2026-10-16
- 范围：知识库、训练材料、提示和 skill

## 背景

社会调查所需材料涉及版权、个人信息、方法适用边界、翻译准确性和场域偏差。公开来源不等于允许全文再分发；模型生成的摘要或训练样例也不能绕过来源核查。

## 决策

材料按“候选收集 → 权利/隐私初筛 → 内容与事实核查 → 双语检查 → prompt/skill 影响评估 → 独立审计 → 人工批准 → 版本化导入”推进。公开运行时只接受 `approved` 且未撤销的来源登记、短摘要、可引用片段和结构化卡片；原始书籍全文、OCR、切片、真实访谈和内部日志保留在私有审计区。生成候选的审计代理不得自行批准候选。

## 后果

- 新中英文材料在人工审阅前不能进入 Wenjin runtime。
- 每个条目需要来源 URL/DOI、许可状态、场域和方法标签、隐私状态、版本哈希与撤销记录。
- 运行时导入必须可重建、可撤销，并保留审核证据。

## 验证

知识阶段需要 schema/manifest validator、独立审计报告、版权/隐私复核和人工批准记录；目前候选仍为私有 `needs_review`，不构成公开 runtime 内容。
