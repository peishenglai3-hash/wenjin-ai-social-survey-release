# ADR-0002：协作研究模式 V1 不做实时共同编辑

- 状态：Accepted
- 日期：2026-10-16
- 范围：协作研究模式

## 背景

研究协作需要成员、角色、版本、审核和审计，但实时共同编辑会引入冲突合并、离线同步、权限竞态和敏感材料广播等额外复杂度。第一版目标是轻量、可回滚并保持已有单人研究路径稳定。

## 决策

V1 只实现项目/成员/角色/邀请、版本化研究材料、批注、审核任务、审计事件和脱敏分享；采用显式保存与版本提交，不实现实时共同编辑。所有敏感实体必须经过用户身份、项目成员关系、角色和对象归属检查。

## 后果

- 先保证可追溯、可撤销和权限矩阵，而不是追求多人同时编辑体验。
- 未来若引入实时协作，必须另立协议、冲突模型、安全评审和迁移计划。
- 旧版单人研究功能不因协作模块启用而改变默认语义。

## 验证

协作阶段需要双用户权限矩阵、版本/审核流程、审计事件和浏览器 smoke；实时共同编辑不属于本版本验收范围。
