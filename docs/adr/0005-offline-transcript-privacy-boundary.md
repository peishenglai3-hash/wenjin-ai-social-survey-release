# ADR-0005：离线访谈草稿的隐私边界

- 状态：Accepted / Implemented in evolution branch
- 日期：2026-10-16
- 范围：田野自动保存、PWA 缓存、账号切换

## 背景

田野场景需要在不稳定网络下暂存转写、笔记和摘要。旧实现把完整 payload 放入未分用户的 `localStorage`，并允许 Service Worker 对 `/api/*` 使用 `NetworkFirst` 缓存；这会让敏感内容长期残留，且可能在同一浏览器的账号之间混用。

## 决策

- 离线队列改用 `sessionStorage`，键名包含当前 JWT subject、已保存 profile id、访客 id 或 anonymous 作用域。
- 每条队列项最多保留 72 小时，最多保留 100 条；过期项读取时即丢弃。
- 退出、进入访客模式或显式清理时删除当前会话中的全部 v2 队列以及旧版无归属 `localStorage` 队列。
- 旧版队列没有可信 owner，首次加载直接清理，不自动迁移到当前账号。
- Service Worker 对 `/api/*` 使用 `NetworkOnly`，不缓存认证、访谈、provider 或调查结果。
- 401/403 不会把队列当作永久失败删除；它们会保留到用户重新认证。其他 4xx 视为不可重试请求并丢弃。

## 后果

- 页面刷新仍可保留同一标签页内的离线草稿，但关闭标签页/应用后不承诺恢复；这是降低长期敏感数据残留的明确取舍。
- `sessionStorage` 不是加密容器，受控设备、浏览器扩展或同会话 XSS 仍可能读取草稿；生产部署仍需 HTTPS、CSP、最小化浏览器权限和设备侧保护。
- 真实 PWA 安装、断网恢复、账号切换和存储配额仍需要浏览器验收，不能仅以单元测试替代。
