# Prompt 与 skill 校准说明

本仓库的内置 prompt/skill 以“专业知识边界”和“调查赋能”两条轴校准。它们帮助研究者拆解问题、设计调查、整理田野材料和提出分析候选，但不能替代伦理审查、代表性判断、最终编码或研究结论。

## 统一硬约束

`backend/app/skills/base.py` 会为每个内置 skill 的 `system_prompt` 追加统一守则：

- 将原始材料、证据、推断和建议分层；证据不足时显式保留不确定性。
- 不编造文献、法规、统计数字、样本、受访者经历或量表信效度。
- 以研究目的最小化身份信息，提醒同意、撤回、保留期限和场域风险。
- AI 只产生候选，不自动批准伦理、编码、事实、权限或公开发布。
- 说明适用场域、语言/文化限制、偏差和失败条件。

## 分模块核验

| skill/prompt | 专业知识检查 | 调查赋能输出 | 当前处理 |
|---|---|---|---|
| questionnaire | 构念、量表、题项、信效度、翻译适配、版权 | 题目草案、设计意图、预测试清单 | 量表数字与来源必须逐项复核，候选不视为事实 |
| topic_argumentation | 理论—问题—方法—抽样的匹配 | 研究问题、可行性、局限和下一步 | 不允许把建议文献当作已核验书目 |
| fieldwork_coach | 中立追问、关系、非语言线索 | 现场追问和风险提醒 | 不输出身份推断或诊断 |
| transcript_analysis / qualitative_coding | 证据片段、编码、负例和反身性 | 可审阅的编码候选 | 不能自动写入编码簿或研究结论 |
| quantitative_analysis | 变量、样本、统计假设、不确定性 | 分析路径和结果解释框架 | 无真实数据时不生成虚假结果 |
| sampling_design | 总体、抽样框、非响应和外推边界 | 抽样方案与质量控制 | 样本量只作条件化估计 |
| literature_review | 检索、来源层级、引用和研究空白 | 检索策略与证据索引 | 需要研究者核验 DOI、版本和许可 |
| report_generator / reference_membrane / image_analysis | 场域、来源、文化与隐私边界 | 结构化整理和行动建议 | 输出仍需人工审阅、脱敏和事实核查 |

## 知识包关系

内置 prompt 中的通用模板不是对第三方书籍、论文或训练材料的再分发。部署者提供的知识包必须先通过 [`KNOWLEDGE_INGESTION.md`](KNOWLEDGE_INGESTION.md) 的来源、许可、隐私、双语和独立审计门；未批准材料不能以 prompt、skill 或切片形式进入 runtime。
